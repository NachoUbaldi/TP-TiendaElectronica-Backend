# 🛒 Tienda Electrónica & Hardware - Frontend (React + Vite)

Frontend desarrollado con **React 18**, **React Router v6**, **CSS3** y componentes animados inspirados en **React Bits** (`BlurText`, `ShinyText`, `GradientText`, `DecryptedText`, `CountUp`, `SpotlightCard`, `AuroraBackground`, `Magnet`), con paleta **Violeta, Blanco y Negro**.

## 🚀 Instalación y Ejecución

1. **Instalar dependencias:**
   ```bash
   cd TP-TiendaElectronica-Frontend
   npm install
   ```

2. **Iniciar servidor de desarrollo (puerto 3000):**
   ```bash
   npm run dev
   ```
   La aplicación se abrirá en `http://localhost:3000` y consumirá por defecto la API REST del backend en `http://localhost:4000/api` (configurable vía `VITE_API_URL`).

   > Si el backend en `http://localhost:4000` aún no está encendido, el frontend activa automáticamente el **Modo Preview Local** con los 23 productos, 4 categorías e información institucional precargados para que puedas navegar y probar todas las vistas de inmediato.
